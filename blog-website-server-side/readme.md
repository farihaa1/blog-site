
# Assignment_category_05

## Blog Website Backend

This repository contains the backend API for the Blog Website. It is built using **Express.js**, **MongoDB**, **JWT Authentication**, and **CORS**. The backend serves to handle blog posts, wishlist management, and user authentication using Firebase Authentication.

## Features

- **User Authentication**: JWT-based authentication for secure user sessions.
- **Blog Management**: CRUD operations for blogs.
- **Comments**: Allows users to add and view comments on blogs.
- **Wishlist**: Users can add blogs to their wishlist.
- **Featured Blogs**: Fetches blogs based on word count.
- **Recent Blogs**: Fetches the latest 6 blogs.
- **Search & Filter**: Search blogs by title and filter by category.
